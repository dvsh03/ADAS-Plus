# Hardware Subsystem

This directory contains circuit schematics, pinout connections, PCB layouts, and wiring guides for **ADAS-Plus**.

## 📁 Modules

- **[`schematics/`](schematics/)**: Circuit schematics and component diagrams.
- **[`pcb/`](pcb/)**: PCB design layout files (Gerber files, KiCad projects).
- **[`wiring/`](wiring/)**: GPIO pin connection matrices and voltage divider details.
