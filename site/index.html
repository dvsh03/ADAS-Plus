Real-Time Road Hazard & Animal Perception
Engineered for Edge Vehicles

Stray animals, unexpected pedestrians, and unlit roadway obstacles create severe collision hazards, especially in low-light night driving. ADAS-Plus combines wireless optical capture, an edge neural network (YOLOv3-Tiny), ultrasonic ranging, and microwave Doppler radar to warn drivers in real time at short range (about 5–6 m prototype range) during low-speed maneuvers.

Perception Pipeline

How ADAS+ Decides & Warns

A multi-threaded edge architecture coordinates computer vision, ultrasonic ranging, radar motion checking, and automated night illumination.

1

See

ESP32-CAM wireless optical node captures frames using an OV2640 sensor and serves a low-latency HTTP MJPEG stream at 320×240 resolution.

ESP32-CAM :81/stream
2

Detect

YOLOv3-Tiny runs inference on edge frames (192×192), filtering 14 road obstacle classes with a confidence threshold $\ge 28\%$.

Darknet / Ultralytics
3

Measure

Vision target acquisition un-gates the HC-SR04 ultrasonic sensor. A 5-sample median filter smooths road bounce while the HB100 24 GHz Doppler radar validates motion.

5-Sample Median Filter
4

Decide

State engine maps distance to hazard zones with a 2.5 s hysteresis grace period to eliminate alert flickering during road bumps.

<3.0m Caution | <1.5m Danger
5

Warn

Triggers an active buzzer (pulsed chimes or continuous alarm tone), powers on 850 nm IR LEDs in dark conditions, and broadcasts telemetry to the web dashboard.

Buzzer (GPIO 18) + IR LED
Current Prototype Hardware

Inside the Working Prototype

Verified components actively wired and executed in the experimental prototype codebase.

Raspberry Pi Zero W / PC

Central edge computing host executing multi-threaded YOLOv3-Tiny inference, GPIO sensor polling, collision state logic, and the Flask web telemetry server.

Primary Platform Tested SBC

ESP32-CAM (OV2640)

Low-power wireless optical capture node providing high-throughput MJPEG video frames over 2.4 GHz local Wi-Fi to the central edge processor.

Optical Node HTTP :81/stream

HC-SR04 Ultrasonic Sensor

Precision short-range distance measurement (2 cm to 400 cm) to confirmed obstacles; gated by visual target detection with 5-sample median noise filtering.

Range Sensor GPIO 23 (Trig) / 24 (Echo)

HB100 24 GHz Doppler Radar

Microwave motion sensing operating at 24.125 GHz; validates physical obstacle movement independently of ambient optical glare, fog, or dust.

Motion Radar GPIO 25 (Motion In)

850 nm High-Power IR LED Board

Active night-vision illuminator automatically energized via GPIO 12 when camera frame grayscale luminance drops below safety threshold (<55).

Night Assist GPIO 12 (Driver Out)

Active Buzzer

Acoustic collision warning actuator delivering graded driver alerts: intermittent pulsed warning tones in Caution zone and a continuous tone in Danger zone.

Audio Alert GPIO 18 (Buzzer Out)

Architecture Roadmap

Today's Prototype vs. Planned Concept

Honest boundary between the working experimental prototype and future production upgrades.

Today: Working Prototype

Built & Verified
  • ✓ Detection Range: Prototype detection range is about 5–6 m; suited for low-speed demonstrations.
  • ✓ Driver Alert Only: Warns driver via active buzzer chimes and web UI; does NOT apply vehicle brakes.
  • ✓ Edge Computing Node: Raspberry Pi Zero W / PC runs multi-threaded detection and sensor fusion.
  • ✓ Wireless Optical Node: ESP32-CAM streams MJPEG frames over 2.4 GHz local Wi-Fi.
  • ✓ Sensor Fusion: HC-SR04 ultrasonic distance sensor with 5-sample median noise filtering and HB100 radar motion checking.
  • ✓ Active Night Assist: 850 nm high-power IR LED board triggered automatically in low ambient light.
  • ✓ Web Dashboard: Lightweight Flask HTTP server serving live stream and JSON telemetry API (/status).

Planned, Not Built Yet

Planned Concept
  • ◷ Planned: Target Detection Range (100–120 m) — Target range 100–120 m with an automotive long-range radar, AI acceleration module, and low-light vision module (design target, not measured or built yet).
  • ◷ Planned: Automatic Emergency Braking (AEB) & Seatbelt-Style Chime — Actuates vehicle braking systems automatically to halt car before impact while sounding a rapid seatbelt-style acoustic warning chime. (Planned concept, not built yet).
  • ◷ Planned: High-Performance Edge Computing Unit — Upgrade from Raspberry Pi Zero W for faster on-device inference and higher FPS.
  • ◷ Planned: Dedicated AI Acceleration Module — Dedicated NPU to run detection in real time on the vehicle.
  • ◷ Planned: Automotive Long-Range Radar Sensor — Replace HB100 radar with automotive-grade sensor for longer range and reliable distance data.
  • ◷ Planned: Low-Light Vision Module — Replace ESP32-CAM and IR LED board with high-sensitivity low-light vision module for night detection.
  • ◷ Planned: Waterproof Distance Sensor — Replace HC-SR04 with a waterproof short-range sensor for outdoor rain and dust resilience.
  • ◷ Planned: Vehicle CAN Bus Interface Module — To connect directly with vehicle speedometers and ECU systems.
  • ◷ Planned: Automotive Power Protection Unit — For stable and safe power conditioning from the 12V vehicle battery.
  • ◷ Planned: In-Vehicle Information Display — Intelligent driver alert display replacing the browser dashboard for cabin use.

Frequently Asked Questions

Common Questions & Clarifications

Clear answers about current prototype capabilities, planned upgrades, and simulation models.

Q: What is the detection range?

The current prototype detects at about 5–6 m, so it suits low-speed use. The planned production-grade version targets 100–120 m using upgraded hardware. That target has not been built or measured yet.

Q: Does it work at night?

In the prototype, night operation relies on automated 850 nm high-power IR LED illumination triggered when camera luminance drops below threshold (<55), functioning within the prototype's short 5–6 m range. The planned version targets an automotive-grade low-light vision module for extended range (design target, not measured).

Q: Are the numbers in the simulation real?

Simulation speeds, distances, stopping times, and warning levels are illustrative engineering models to demonstrate perception and braking concepts, not tested physical limits. The prototype range of about 5–6 m is the owner's stated figure; the 100–120 m figure is an unbuilt future design target.
