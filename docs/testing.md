# ADAS-Plus Testing & Benchmarking

## 🧪 Test Procedures

1. **Object Detection Latency Test**: Measure inference time per frame across input sizes (192x192, 320x320, 416x416).
2. **Sensor Accuracy Test**: Compare HC-SR04 readings against laser measure targets at 0.5m, 1.0m, 2.0m, and 3.0m.
3. **Alert Response Time**: Time interval between obstacle detection and buzzer actuation.
4. **Stream Stability**: Continuous 24-hour MJPEG stream stability test over Wi-Fi.
